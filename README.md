Excel Data Cleaning & Reporting Project
Project Overview

This project focuses on retail sales analysis using Google Sheets. The project includes data cleaning, exploratory data analysis (EDA), pivot tables, charts, dashboard creation, and business insights reporting.

Objectives
Clean and validate retail sales data
Analyze sales and profit trends
Identify top-performing categories and regions
Build interactive dashboard visualizations
Generate business insights from the dataset
Tools Used

Dashboard Reporting

Currency and percentage formatting
Profit margin calculations
Key Features
KPI Cards
Sales Trend Analysis
Regional Profit Analysis
Customer Analysis
Interactive Filters/Slicers
Dashboard Visualization
Key Insights
Technology category generated highest sales.
West region produced highest profit.
Consumer segment contributed maximum revenue.
Some products generated negative profit margins.
